# Swarm Protocol

Top-down 3D шутер с прокачкой в духе SYNTHETIK и Vampire Survivors. Работает в браузере, написан на Three.js и TypeScript, без игрового движка.

Арена, бесконечные орды и выбор апгрейда на каждом уровне. Каждые 45 секунд игрока окружают кольцом, каждые 2 минуты приходит босс «Матка».

## Запуск

```bash
npm install
npm run dev        # dev-сервер Vite с hot reload
npm run build      # typecheck + сборка в dist/index.html (один файл)
npm run preview    # посмотреть собранную версию
npm run typecheck  # только tsc
```

Сборка — один самодостаточный `dist/index.html`: JS и CSS встроены через `vite-plugin-singlefile`. Его можно открыть с диска или опубликовать как артефакт на claude.ai. Из внешнего грузятся только шрифты Google Fonts.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | движение |
| Мышь, ЛКМ | прицел, огонь |
| R | перезарядка; второе нажатие R в жёлтой зоне — мгновенная перезарядка и +50% урона на магазин, мимо — клин |
| Пробел / Shift | рывок с неуязвимостью |
| 1 2 3 / колесо | смена оружия |
| Esc / P | пауза |
| M | звук вкл/выкл |

## Структура

```
src/
  main.ts       точка входа: игровой цикл, состояния (старт, пауза, левелап, смерть), ввод → действия
  config.ts     все числа для баланса: оружие, враги, темп, лимиты, кривая опыта
  state.ts      общее изменяемое состояние (G, P, S) и типы сущностей
  scene.ts      renderer, камера, свет, арена, меши игрока, instanced-пулы
  arena.ts      случайные колонны-укрытия и коллизии с ними
  input.ts      клавиатура, мышь, луч прицела на плоскость y = 1
  player.ts     движение, рывок, получение урона
  weapons.ts    стрельба, смена оружия, активная перезарядка
  combat.ts     пули игрока, урон, криты, взрывы, смерть врага и дроп
  enemies.ts    спавн-директор (волны, кольца, босс), ИИ, раздвигание толпы, вражеские снаряды
  grid.ts       пространственный хеш для коллизий
  pickups.ts    кристаллы опыта, аптечки, магнит, начисление уровней
  abilities.ts  пассивки: дроны-спутники и статическое поле
  upgrades.ts   пул апгрейдов и экран выбора
  hud.ts        DOM-интерфейс (пишет в DOM только изменившиеся значения)
  render.ts     перенос состояния в меши, камера с упреждением и тряской
  fx.ts         частицы, кольца взрывов, цифры урона, баннеры
  audio.ts      синтезированные звуки на WebAudio, без ассетов
  style.css
```

Как устроено:

- **Состояние.** Всё живёт в трёх объектах из `state.ts`: `G` (мир), `P` (игрок), `S` (статы от апгрейдов). Модули меняют поля этих объектов и не переприсваивают экспорты, поэтому все системы видят одни и те же данные.
- **Кадр.** `update()` в `main.ts` вызывает системы по порядку, в конце кадра один раз удаляет мёртвые сущности. Индексы в `grid` действительны только до этой очистки.
- **Рендер.** Враги, пули, кристаллы и частицы рисуются через `InstancedMesh`: один draw call на тип. Сотни врагов на экране не тормозят.
- **Пули.** Двигаются подшагами по 0.35 юнита, поэтому быстрые пули не пролетают сквозь мелких врагов.
- **Отладка.** `window.__swarm` в консоли даёт доступ к состоянию. Например, `__swarm.G.time = 115` — и через 5 секунд придёт босс.
